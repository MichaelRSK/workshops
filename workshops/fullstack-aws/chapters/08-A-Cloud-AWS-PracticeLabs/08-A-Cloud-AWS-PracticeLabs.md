# 08-A-Cloud-AWS-PracticeLabs

## 🎯 Phase Goal
Gain hands-on familiarity with foundational AWS cloud infrastructure services required to host scalable full-stack applications.

## 🛠️ Concepts & Topics Covered
* **Compute & Serverless:** AWS EC2, AWS Lambda.
* **Networking & Content Delivery:** AWS VPC, CloudFront.
* **Database & Storage:** DocumentDB / RDS, AWS S3.
* **Security:** AWS IAM roles, policies, and security groups.

## 📋 Module Roadmap & Tasks

### Step 1: Core Networking & Identity Setup
* Configure IAM roles and access policy boundaries.
* Set up a custom Virtual Private Cloud (VPC) with public/private subnets.

### Step 2: Storage & Database Lab
* Launch an Amazon DocumentDB instance (MongoDB-compatible) in a private subnet.
* Configure S3 bucket for web client static asset storage.

### Step 3: Compute & Serverless Execution Lab
* Launch an EC2 instance with proper Security Group rules (ports 80, 443, 22).
* Deploy a test Python script to AWS Lambda.
